# Irysh Labs — Website

Landing page Irysh Labs (Next.js + Tailwind), siap deploy ke Vercel.

## Jalankan di laptop
```bash
npm install
npm run dev
```
Buka http://localhost:3000

## Ubah konten
- Kontak (WhatsApp, Telegram, email): bagian `KONTAK` di paling atas `app/page.tsx`
- Paket, fitur, FAQ: array `PAKET`, `FITUR`, `FAQ` di `app/page.tsx`
- Warna brand: `app/globals.css`
- Logo: `public/logo-mark.svg`, ikon tab browser: `app/icon.png`
